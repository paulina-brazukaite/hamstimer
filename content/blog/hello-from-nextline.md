## How posts work

Each post is one Markdown file in `content/blog/`. The file name is the URL: this one is `hello-from-nextline.md`, so it lives at `/blog/hello-from-nextline`.

At the top of the file, between the `---` lines, are the title, a one-sentence description for search results and link previews, and the date. Add `draft: true` to keep a post out of the blog while you work on it.

To publish:

1. Add the `.md` file to `content/blog/`.
2. Commit and push.
3. Vercel rebuilds, and the post appears on `/blog`, in the sitemap and with its own share image.

## What formatting looks like

Plain paragraphs, [links to other pages](/about), *emphasis* and `inline code` all work. So do lists:

- one line about what you're working on,
- a note about your very next step,
- one key to pick it back up.
